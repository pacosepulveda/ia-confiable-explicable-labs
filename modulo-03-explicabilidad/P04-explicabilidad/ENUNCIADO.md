# P04 — Explicabilidad

## P04A — Velora Finance

Analizar el comportamiento de un modelo de riesgo desde diferentes perspectivas:

1. comparar un modelo interpretable por diseño y un modelo de mayor complejidad;
2. obtener una explicación global mediante SHAP;
3. seleccionar una solicitud y obtener una explicación local SHAP;
4. explicar el mismo caso mediante LIME;
5. comprobar la estabilidad de LIME ante distintos muestreos;
6. generar contrafactuales con restricciones de factibilidad;
7. distinguir atribución, aproximación local y contrafactuales.

## P04B — Visión

Aplicar métodos de atribución a una imagen clasificada por un modelo preentrenado:

1. obtener el top-5 de clases;
2. seleccionar la clase objetivo;
3. generar un mapa Saliency;
4. generar Integrated Gradients;
5. variar target y número de pasos;
6. analizar los límites de las heatmaps de atribución.
