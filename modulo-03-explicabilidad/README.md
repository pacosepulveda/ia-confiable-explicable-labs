# Módulo 03 — Explicabilidad

Este módulo trabaja técnicas para comprender y comunicar por qué un sistema de IA produce determinadas predicciones.

## Prácticas

### [P04 — Explicabilidad tabular y visión](./P04-explicabilidad/)

La práctica combina dos escenarios:

- **P04A — Datos tabulares:** SHAP, LIME y explicaciones contrafactuales sobre el caso Velora Finance.
- **P04B — Visión:** mapas de saliencia e Integrated Gradients para interpretar predicciones de un modelo de imagen.
