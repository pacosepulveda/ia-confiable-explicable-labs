# Módulo 05 — Gobernanza y auditoría

Este módulo integra los conceptos trabajados durante el curso en una visión de gobernanza y auditoría de un sistema de IA de extremo a extremo.

## Prácticas

### [P07 — Auditoría end-to-end](./P07-auditoria-end-to-end/)

Auditoría completa del sistema de Velora Finance: contexto, evidencias, integridad, controles, trazabilidad, rendimiento, fairness, privacidad, explicabilidad, IA generativa, monitorización, incidentes, riesgos y decisión de despliegue.

La práctica conecta estos elementos con marcos y referencias como **NIST AI RMF**, **ISO/IEC 42001** y el **EU AI Act**.
