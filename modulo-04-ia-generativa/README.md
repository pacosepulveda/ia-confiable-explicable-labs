# Módulo 04 — IA generativa confiable

Este módulo traslada los principios de IA confiable a sistemas generativos, trabajando tanto con arquitecturas RAG como con agentes que utilizan herramientas.

## Prácticas

### [P05 — RAG confiable](./P05-rag-confiable/)

Análisis práctico de mecanismos para mejorar la trazabilidad, el uso de contexto y la fiabilidad de un sistema RAG.

### [P06 — Agentes confiables](./P06-agentes-confiables/)

Construcción y análisis de un agente con Amazon Bedrock Mantle, prestando atención al uso controlado de herramientas y a los riesgos propios de los sistemas agénticos.
