# IA Confiable y Explicable — Laboratorios

Repositorio de prácticas del curso **Inteligencia Artificial Confiable y Explicable**.

Los laboratorios están organizados por módulo y siguen un caso común basado en **Velora Finance**. Cada práctica incluye un enunciado y uno o varios notebooks preparados para trabajar durante la formación.

## Cómo trabajar con las prácticas

1. Entra en el módulo correspondiente.
2. Abre la carpeta de la práctica.
3. Consulta `ENUNCIADO.md` para conocer el objetivo y las tareas.
4. Abre el notebook indicado en el README de la práctica y sigue las instrucciones.

Los notebooks están preparados para reducir el código accesorio y centrar el trabajo en la toma de decisiones, la experimentación y el análisis de resultados.
